KALDER GREY POETRY SITE

This is a simple static website.

Files:
- index.html — site content
- styles.css — design and responsive layout

To customize:
1. Open index.html in a browser to preview it.
2. Replace the placeholder poem titles/excerpts with your poems.
3. Replace the # links for TikTok and Instagram with your real profile links.
4. Upload index.html and styles.css to any static web host.
